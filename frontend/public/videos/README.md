# Featured project walkthrough videos

The desktop shortcuts and Projects window expect these static files:

- `frhelp-demo.mp4` — walkthrough for FrHelp
- `paisa-demo.mp4` — walkthrough for Paisa

Copy the two supplied MP4 files into this directory using those exact filenames. Vite serves files in `frontend/public` from the site root, so the app links are `/videos/frhelp-demo.mp4` and `/videos/paisa-demo.mp4`.

These videos are intentionally kept out of GitHub's text-file editing API; add the binary files locally and push them with Git (or use Git LFS if your repository has it configured).
